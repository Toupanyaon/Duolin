## กติกาของเกม

- **สมัคร / ล็อกอิน** ด้วยชื่อผู้เล่นและรหัสผ่าน (รหัสผ่านเก็บเป็น SHA-256 hash ไม่เก็บตัวจริง)
- **หัวใจ** มี 3 ดวงต่อวัน ตอบผิดในบทเรียน −1 ดวง ขึ้นวันใหม่หัวใจเต็มอัตโนมัติ
- **หัวใจหมด** → เข้า Practice Mode ทวนข้อที่เคยผิด ตอบถูกครบ 5 ข้อ = ได้หัวใจคืน 1 ดวง แล้วกลับไปเล่นบทเรียนต่อจากข้อที่ค้างไว้
- **XP**: ตอบถูก +10 XP, จบบทเรียน +20 XP
- **Level** = `XP // 100 + 1` (ทุก 100 XP ขึ้น 1 เลเวล)
- **Streak**: เล่น (ตอบคำถาม) ติดต่อกันทุกวัน streak จะเพิ่ม ถ้าขาดไปเกิน 1 วัน รีเซ็ตเป็น 0
- **Leaderboard**: เรียงตาม XP มากสุด → ถ้าเท่ากันดู streak → ถ้ายังเท่ากัน ใครถึง XP นั้นก่อนได้อันดับดีกว่า
- **เควสต์ประจำวัน** 3 อย่าง และ **Achievement** 7 อย่าง

## อธิบายโค้ด `questions.py`

ไฟล์นี้มีตัวแปรเดียวคือ `LESSONS` เป็น list ของบทเรียน แต่ละบทเป็น dict:

```python
{
    "name": "Greetings",          # ชื่อบทเรียน แสดงบนปุ่มในเมนู
    "questions": [ ... ],         # list ของคำถาม
}
```

คำถามมี 2 แบบ ดูจาก key `"type"`:

**1) `"choice"` — ปรนัย เลือก 1 ข้อ**
```python
{"type": "choice",
 "question": 'What does "Hola" mean?',
 "options": ["Hello", "Goodbye", "Thanks", "Please"],   # ตัวเลือกทั้งหมด
 "answer": "Hello"}                                      # คำตอบที่ถูก (string ต้องตรงกับตัวเลือกตัวหนึ่ง)
```

**2) `"order"` — เรียงคำให้เป็นประโยค**
```python
{"type": "order",
 "question": 'Translate: "Good morning"',
 "answer": ["Buenos", "días"],    # คำที่ถูก เรียงตามลำดับที่ถูก
 "extra": ["noches"]}             # คำหลอก ผสมเข้าไปให้ยากขึ้น (ไม่ใส่ก็ได้)
```

ตอนนี้มี 3 บทเรียน (Greetings, Food, Family) บทละ 5 ข้อ

**รหัสคำถาม (question id)** ในเกมจะอ้างถึงคำถามแต่ละข้อด้วย string `"บทที่-ข้อที่"` เช่น `"2-3"` = บทที่ index 2 (Family) ข้อ index 3
(นับจาก 0 ทั้งคู่) ใช้เก็บลิสต์ข้อที่ตอบผิด

### 1. ค่าคงที่และการตั้งค่า

```python
WIDTH, HEIGHT = 800, 600
SAVE_FILE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "save_data.json")
MAX_HEARTS = 3
PRACTICE_GOAL = 5
```

- `SAVE_FILE` ใช้ path ของโฟลเดอร์ที่ `main.py` อยู่ ไม่ว่าจะรันเกมจากโฟลเดอร์ไหน ไฟล์เซฟก็จะอยู่ข้าง ๆ `main.py` เสมอ
- `MAX_HEARTS` จำนวนหัวใจสูงสุด, `PRACTICE_GOAL` จำนวนข้อที่ต้องตอบถูกใน Practice เพื่อได้หัวใจคืน 1 ดวง
- สี (`WHITE`, `GREEN`, `RED`, ...) เป็น tuple RGB ใช้ทั่วทั้งเกม

**`QUESTS`** — เควสต์ประจำวัน เป็น tuple `(ข้อความ, key, เป้าหมาย)`

```python
("Earn 50 XP", "xp", 50)
```
`key` คือชื่อช่องใน `player["daily"]` ที่ใช้นับความคืบหน้า เช่น `player["daily"]["xp"]` ต้องถึง 50

**`ACHIEVEMENTS`** — เป็น tuple `(ชื่อ, คำอธิบาย, เงื่อนไข)` โดย *เงื่อนไข* เป็น `lambda` ที่รับข้อมูลผู้เล่น `p` แล้วคืน `True/False`

| ชื่อ | เงื่อนไข |
|------|----------|
| First Lesson | จบบทเรียนอย่างน้อย 1 บท |
| XP Hunter | XP ≥ 100 |
| On Fire | streak ≥ 3 วัน |
| Perfect! | จบบทเรียนโดยไม่ผิดเลย (`p["perfect"]`) |
| Comeback | เคยได้หัวใจคืนจาก Practice (`p["restored"]`) |
| Quest Master | ทำเควสต์ประจำวันครบทุกอันในวันเดียว |
| Graduate | จบครบทุกบทเรียน |

ข้อดีของการเขียนเงื่อนไขเป็น lambda คือเพิ่ม Achievement ใหม่ได้โดยเพิ่มแค่บรรทัดเดียว ไม่ต้องแก้ส่วนอื่น

### 2. ระบบบันทึก / โหลดข้อมูล

| ฟังก์ชัน | หน้าที่ |
|----------|---------|
| `today()` | คืนวันที่วันนี้เป็น string รูปแบบ `"2026-11-02"` ใช้เทียบว่าเป็นวันใหม่หรือยัง |
| `hash_password(pw)` | แปลงรหัสผ่านเป็น SHA-256 hex string ตอนล็อกอินจะ hash รหัสที่พิมพ์แล้วเทียบกับที่เก็บไว้ |
| `load_data()` | อ่าน `save_data.json` ถ้ายังไม่มีไฟล์ คืน `{}` (dict ว่าง) |
| `save_data(data)` | เขียนข้อมูลทั้งหมดลงไฟล์ (`indent=2` ให้อ่านง่าย, `ensure_ascii=False` ให้เก็บตัวอักษรอย่าง `á` ได้ตรง ๆ) |
| `new_player(pw)` | สร้าง dict ข้อมูลผู้เล่นใหม่ที่มีค่าเริ่มต้นครบทุกช่อง |

ข้อมูลทั้งหมด (`self.data`) เป็น dict ที่ key คือชื่อผู้เล่น value คือข้อมูลผู้เล่นคนนั้น
เกมบันทึกลงไฟล์บ่อย ๆ (หลังตอบทุกข้อ, จบบท, ออกจากบท, ล็อกเอาต์, ปิดเกม) เพื่อไม่ให้ข้อมูลหาย

### 3. คลาส `Game` และตัวแปรสถานะ

`__init__` ตั้งค่า Pygame (หน้าต่าง, นาฬิกา, ฟอนต์ 4 ขนาด: `font`, `small`, `big`, `tiny`) แล้วโหลดข้อมูลเซฟ

ตัวแปรสำคัญ:

| ตัวแปร | ความหมาย |
|--------|----------|
| `self.data` | ข้อมูลผู้เล่นทุกคน (โหลดจากไฟล์) |
| `self.user` | ชื่อผู้เล่นที่ล็อกอินอยู่ (`None` = ยังไม่ล็อกอิน) |
| `self.state` | หน้าจอปัจจุบัน เช่น `"login"`, `"menu"`, `"question"` |
| `self.buttons` | ปุ่มทั้งหมดที่วาดในเฟรมนี้ `[(rect, action), ...]` |
| `self.message` | ข้อความแจ้งเตือนสีแดง (เช่น "Wrong password!") |
| `self.popup`, `self.popup_time` | ป๊อปอัปสีทองด้านบน แสดง 2.5 วินาที |
| `self.name_text`, `self.pass_text`, `self.active` | ข้อความที่พิมพ์ในหน้าล็อกอิน และช่องที่กำลังพิมพ์อยู่ |
| `self.mode` | `"lesson"` หรือ `"practice"` |
| `self.lesson`, `self.q_index` | บทเรียนและข้อที่กำลังเล่น |
| `self.qid` | รหัสคำถามปัจจุบัน เช่น `"0-2"` |
| `self.question` | dict คำถามปัจจุบัน |
| `self.options`, `self.selected` | ตัวเลือก (สลับลำดับแล้ว) และตัวที่ผู้เล่นเลือก — ใช้กับข้อแบบ `choice` |
| `self.pool`, `self.chosen` | คำที่ยังไม่ได้เลือก และคำที่เลือกแล้วตามลำดับ — ใช้กับข้อแบบ `order` |
| `self.feedback` | `None` = ยังไม่ตรวจ, `"correct"` / `"wrong"` = ตรวจแล้ว |
| `self.mistakes` | จำนวนข้อที่ผิดในบทเรียนรอบนี้ (ใช้เช็ก Perfect) |
| `self.resumed` | บทนี้เล่นต่อจากที่ค้างไว้หรือเปล่า (ถ้าใช่ จะไม่ได้ Perfect) |

**`player` property**
```python
@property
def player(self):
    return self.data[self.user]
```
ทำให้เขียน `self.player["xp"]` แทน `self.data[self.user]["xp"]` ได้ สั้นและอ่านง่ายกว่า

### 4. ระบบหน้าจอ (State machine)

เกมนี้แบ่งเป็นหน้าจอ (state) แต่ละหน้ามีฟังก์ชันวาดชื่อ `draw_<state>`:

| state | ฟังก์ชัน | หน้าจอ |
|-------|----------|--------|
| `login` | `draw_login` | ล็อกอิน / สมัคร |
| `menu` | `draw_menu` | เมนูหลัก เลือกบทเรียน |
| `question` | `draw_question` | หน้าตอบคำถาม (ใช้ทั้ง lesson และ practice) |
| `lesson_done` | `draw_lesson_done` | จบบทเรียน |
| `no_hearts` | `draw_no_hearts` | หัวใจหมด |
| `leaderboard` | `draw_leaderboard` | ตารางอันดับ |
| `quests` | `draw_quests` | เควสต์และ Achievement |

ใน main loop เรียกหน้าจอด้วย
```python
getattr(self, "draw_" + self.state)()
```
คือเอาชื่อ state มาต่อเป็นชื่อเมธอดแล้วเรียก ไม่ต้องเขียน `if/elif` ยาว ๆ อยากเพิ่มหน้าจอใหม่ก็แค่เขียนเมธอด `draw_ชื่อใหม่`

การเปลี่ยนหน้าใช้ `change_state(state)` ซึ่งล้าง `self.message` ด้วย ข้อความเตือนของหน้าเก่าจะได้ไม่ติดไปหน้าใหม่

### 5. ตัวช่วยวาด (Drawing helpers) และระบบปุ่ม

- **`text(msg, x, y, font, color, center)`** — วาดข้อความ ถ้า `center=True` จุด (x, y) คือจุดกึ่งกลาง ไม่งั้นเป็นมุมซ้ายบน
- **`button(label, rect, action, color, text_color, font)`** — วาดปุ่มสี่เหลี่ยมมุมมน
  - ถ้าเมาส์ชี้อยู่ สีจะเข้มขึ้น (ลบ 25 ทุกช่อง RGB) เป็นเอฟเฟกต์ hover
  - เพิ่ม `(rect, action)` เข้า `self.buttons` เพื่อให้ main loop รู้ว่าคลิกตรงไหนต้องทำอะไร
- **`draw_hearts(x, y)`** — วาดวงกลม 3 ดวง สีแดง = หัวใจที่เหลือ สีเทา = ที่เสียไป
- **`draw_header()`** — แถบบนสุดในเมนู แสดงชื่อ, Level, XP, Streak, หัวใจ
- **`notify(msg)`** — ตั้งป๊อปอัปสีทอง (จำเวลาที่ตั้งไว้ใน `popup_time`)

**หลักการของระบบปุ่ม (Immediate-mode UI):** ทุกเฟรมจะล้าง `self.buttons = []` แล้ววาดหน้าจอใหม่ทั้งหมด ปุ่มที่วาดจะลงทะเบียนตัวเองใหม่ทุกเฟรม
ดังนั้นปุ่มที่ "มีอยู่" คือปุ่มที่ถูกวาดในเฟรมล่าสุดเท่านั้น ไม่ต้องสร้าง/ลบออบเจ็กต์ปุ่มเอง

**เทคนิค `lambda i=i:`** — ในลูปที่สร้างปุ่มหลายอัน เช่น
```python
self.button(label, ..., lambda i=i: self.start_lesson(i), color)
```
ต้องเขียน `i=i` เพื่อ "จำค่า i ณ ตอนนั้น" ไว้ ถ้าเขียนแค่ `lambda: self.start_lesson(i)` ทุกปุ่มจะได้ค่า `i` ตัวสุดท้ายของลูปหมด

### 6. Main loop

```python
def run(self):
    while True:
        for event in pygame.event.get():
            ...
        self.screen.fill(WHITE)
        self.buttons = []
        getattr(self, "draw_" + self.state)()
        # วาดป๊อปอัปถ้ายังไม่ครบ 2.5 วินาที
        pygame.display.flip()
        self.clock.tick(30)
```

แต่ละรอบ (เฟรม) ทำ:
1. **จัดการ event**
   - `QUIT` (กดปิดหน้าต่าง) → เซฟแล้วออก
   - คลิกซ้าย → หาปุ่มใน `self.buttons` ที่ตำแหน่งคลิกอยู่ข้างใน แล้วเรียก `action()` (เจออันแรกแล้ว `break`)
   - กดคีย์บอร์ดในหน้าล็อกอิน → `login_keys`
2. **ล้างจอเป็นสีขาว** และล้างลิสต์ปุ่ม
3. **วาดหน้าจอปัจจุบัน**
4. **วาดป๊อปอัป** ถ้าเพิ่งแจ้งเตือนไม่เกิน 2.5 วินาที
5. **แสดงผล** (`flip`) และจำกัดความเร็วที่ 30 FPS

หมายเหตุ: ปุ่มที่คลิกได้คือปุ่มที่วาดใน *เฟรมก่อนหน้า* ซึ่งก็คือสิ่งที่ผู้เล่นเห็นอยู่บนจอพอดี

### 7. หน้าล็อกอิน / สมัคร

- **`login_keys(event)`** — รับการพิมพ์
  - `TAB` สลับช่องชื่อ ↔ รหัสผ่าน
  - `ENTER` = กดล็อกอิน
  - `BACKSPACE` ลบตัวท้าย
  - ตัวอักษรที่พิมพ์ได้ (`isprintable()`) จะต่อท้าย จำกัดไม่เกิน 15 ตัว
  - ใช้ `getattr`/`setattr` กับชื่อตัวแปร (`"name_text"` หรือ `"pass_text"`) เพื่อใช้โค้ดชุดเดียวกับทั้งสองช่อง
- **`draw_login()`** — วาดช่องกรอก 2 ช่อง (รหัสผ่านแสดงเป็น `*`) ช่องที่กำลังพิมพ์มีขอบสีฟ้า คลิกที่ช่องเพื่อเลือกช่องได้ (ช่องกรอกก็ลงทะเบียนใน `self.buttons` เหมือนปุ่ม)
- **`login()`** — ตรวจว่ามีชื่อนี้ไหม แล้วเทียบ hash รหัสผ่าน ผ่านแล้วเรียก `enter_game`
- **`register()`** — ตรวจว่ากรอกครบและชื่อยังไม่ถูกใช้ แล้วสร้างผู้เล่นใหม่ด้วย `new_player` บันทึก และเข้าเกม
- **`enter_game(name)`** — ตั้ง `self.user`, ล้างรหัสผ่านที่พิมพ์ไว้ (ความปลอดภัย), เรียก `refresh_day()` แล้วไปหน้าเมนู
- **`logout()`** — เซฟ แล้วกลับหน้าล็อกอิน

### 8. ระบบรายวัน: หัวใจ, เควสต์, Streak

**`refresh_day()`** — เรียกตอนล็อกอินและก่อนเริ่มบทเรียน เพื่อเช็กว่าขึ้นวันใหม่หรือยัง:
- ถ้า `hearts_date` ไม่ใช่วันนี้ → หัวใจเต็ม 3 ดวง
- ถ้า `daily["date"]` ไม่ใช่วันนี้ → รีเซ็ตตัวนับเควสต์ประจำวัน
- ถ้า `last_play` ไม่ใช่ทั้ง "ว่าง", "วันนี้", หรือ "เมื่อวาน" แปลว่าขาดไปเกิน 1 วัน → `streak = 0`

**`update_streak()`** — เรียกทุกครั้งที่ตอบคำถาม (ตอน `check_answer`):
- ถ้าวันนี้เล่นไปแล้ว → ไม่ทำอะไร (streak เพิ่มได้วันละครั้ง)
- ถ้าเล่นล่าสุดเมื่อวาน → `streak + 1`
- ไม่งั้น (เล่นครั้งแรก หรือขาดไป) → `streak = 1`
- อัปเดต `last_play` เป็นวันนี้

แยกเป็นสองฟังก์ชันเพราะ: `refresh_day` แค่ "ตัด" streak ที่ขาดไปแล้วตอนเข้าเกม ส่วน `update_streak` "นับ" วันนี้ว่าเล่นแล้ว
แค่ล็อกอินเฉย ๆ ไม่นับเป็นการเล่น ต้องตอบคำถามอย่างน้อย 1 ข้อ

### 9. XP และ Achievement

**`add_xp(amount)`** — เพิ่ม XP ทั้งยอดรวม และยอดประจำวัน (`daily["xp"]` สำหรับเควสต์) แล้วบันทึกเวลาไว้ใน `xp_time`
(`xp_time` ใช้ตัดสินใน Leaderboard ว่าใครถึง XP นี้ก่อน)

**`check_achievements()`** — วนดู Achievement ทุกอัน ถ้ายังไม่ได้และเงื่อนไข (lambda) เป็นจริง → เพิ่มเข้าลิสต์และแสดงป๊อปอัป
เรียกหลังตอบทุกข้อและหลังจบบทเรียน

### 10. หน้าเมนู

**`draw_menu()`**
- ฝั่งซ้าย: ปุ่มบทเรียนทุกบท สีของปุ่มบอกสถานะ
  - 🟧 ส้ม `(Resume)` — มีความคืบหน้าค้างไว้ใน `progress`
  - 🟦 ฟ้า `(Done)` — จบแล้ว
  - 🟩 เขียว — ยังไม่เคยเล่น
- ฝั่งขวา: ปุ่ม Practice Mode, Quests & Badges, Leaderboard, Log out
- ด้านล่างขวา: จำนวนข้อผิดที่รอทวน และความคืบหน้า Practice เพื่อได้หัวใจ

หมายเหตุ: key ใน `progress` เป็น string (`"0"`, `"1"`) เพราะ JSON เก็บ key ของ dict เป็น string เท่านั้น
จึงต้องใช้ `str(i)` ทุกครั้งที่อ่าน/เขียน `progress`

### 11. บทเรียนและ Practice Mode

**`start_lesson(i)`**
1. `refresh_day()` เผื่อข้ามวันระหว่างเปิดเกมค้างไว้
2. ถ้าหัวใจเป็น 0 → ไปหน้า `no_hearts`
3. ตั้ง `mode = "lesson"` และเริ่มที่ข้อ `progress[str(i)]` (ถ้าไม่มีเริ่มข้อ 0)
4. `resumed = True` ถ้าไม่ได้เริ่มจากข้อแรก
5. ถ้าข้อที่ค้างไว้เลยข้อสุดท้ายแล้ว (เช่น หัวใจหมดตอนข้อสุดท้าย) → จบบทเลย
6. โหลดคำถามแล้วไปหน้า `question`

**`start_practice()`** — ตั้ง `mode = "practice"` โหลดคำถามแล้วไปหน้า `question` (เล่นได้แม้หัวใจหมด)

**`load_question()`** — เตรียมคำถามข้อถัดไป
- โหมด lesson: `qid = "บท-ข้อ"` ตามลำดับ
- โหมด practice: สุ่มจากลิสต์ข้อที่ผิด (`player["wrong"]`) ถ้าไม่มีข้อผิดเลย สุ่มจากทุกข้อในทุกบท
- แยก `qid` กลับเป็นตัวเลขด้วย `map(int, self.qid.split("-"))` แล้วดึง dict คำถามจาก `LESSONS`
- รีเซ็ต `feedback`, `selected`, `chosen`
- ข้อแบบ `choice`: สลับลำดับตัวเลือกด้วย `random.sample` (ได้ลิสต์ใหม่ ไม่แก้ข้อมูลต้นฉบับ)
- ข้อแบบ `order`: เอาคำตอบ + คำหลอกมารวมกันเป็น `pool` แล้วสลับ

**`quit_question()`** — ปุ่ม `X` มุมซ้ายบน ถ้าอยู่ในบทเรียนและทำไปแล้วอย่างน้อย 1 ข้อ จะจำข้อที่ค้างไว้ใน `progress` แล้วกลับเมนู

**การโต้ตอบกับคำถาม** (ทั้งหมดใช้ได้เฉพาะตอนยังไม่ได้กด Check คือ `feedback is None`):
- `select_option(option)` — เลือกตัวเลือก (ข้อ choice)
- `pick_word(i)` — ย้ายคำจาก `pool` ไปต่อท้าย `chosen` (ข้อ order)
- `remove_word(i)` — ย้ายคำจาก `chosen` กลับไป `pool` (ข้อ order)

**`draw_tiles(words, y, on_click)`** — วาดคำเป็นปุ่มเรียงจากซ้ายไปขวา ความกว้างแต่ละปุ่มคำนวณจากความยาวคำ (`font.size(word)`)

**`draw_question()`** — วาดหน้าตอบคำถาม
- **แถบบน**: ปุ่ม `X`, แถบความคืบหน้าสีเขียว (โหมด lesson) หรือข้อความนับ Practice (โหมด practice), หัวใจ
- **ตรงกลาง**: โจทย์ และ
  - choice: ปุ่มตัวเลือกเรียงลงมา ตัวที่เลือกเป็นสีฟ้า
  - order: แถวบน (เหนือเส้น) = คำที่เลือกแล้ว, แถวล่าง = คำให้เลือก คลิกเพื่อย้ายไปมา
- **แถบล่าง**:
  - ยังไม่ตรวจ: ปุ่ม `Check` (เป็นสีเทาถ้ายังไม่ได้เลือกอะไร)
  - ตรวจแล้ว: พื้นเขียว "Correct! +10 XP" หรือพื้นแดง "Wrong! Correct answer: ..." พร้อมปุ่ม `Continue`

### 12. การตรวจคำตอบ

**`check_answer()`**
1. ถ้ายังไม่ได้เลือกอะไร → ไม่ทำอะไร
2. ตรวจถูก/ผิด
   - choice: `selected == answer`
   - order: `chosen == answer` (เทียบ list ทั้งลำดับและคำต้องตรงกันหมด)
3. `update_streak()` นับว่าวันนี้เล่นแล้ว
4. **ถ้าถูก**:
   - `feedback = "correct"`, +10 XP, เควสต์ `correct` +1
   - ถ้าอยู่ใน Practice: ลบข้อนี้ออกจากลิสต์ข้อผิด และถ้าหัวใจยังไม่เต็ม `practice_correct` +1
     → ครบ 5 ได้หัวใจ +1, รีเซ็ตตัวนับ, ตั้ง `restored = True` (สำหรับ Achievement Comeback) และแสดงป๊อปอัป
5. **ถ้าผิด**:
   - `feedback = "wrong"`, เพิ่มข้อนี้เข้าลิสต์ข้อผิด (ถ้ายังไม่มี)
   - ถ้าอยู่ในบทเรียน: หัวใจ −1 และ `mistakes` +1 (ใน Practice ตอบผิดไม่เสียหัวใจ)
6. เช็ก Achievement และบันทึก

### 13. ไปข้อต่อไป / จบบทเรียน

**`next_question()`** — ปุ่ม `Continue`
- Practice: โหลดข้อสุ่มใหม่เลย (เล่นไปเรื่อย ๆ จนกด `X`)
- Lesson: `q_index` +1 แล้ว
  - ถ้าหัวใจหมด → จำข้อที่ค้างไว้ใน `progress` แล้วไปหน้า `no_hearts`
  - ถ้าครบทุกข้อ → `finish_lesson()`
  - ไม่งั้น → โหลดข้อถัดไป

**`finish_lesson()`**
- +20 XP โบนัส, เควสต์ `lessons` +1
- ลบความคืบหน้าค้างของบทนี้ออก (`progress.pop`)
- เพิ่มบทนี้ใน `completed` (ถ้ายังไม่มี)
- ถ้าไม่ผิดเลยและไม่ได้เล่นต่อจากที่ค้าง → `perfect = True`
- เช็ก Achievement, บันทึก, ไปหน้า `lesson_done`

**`draw_lesson_done()`** — หน้าแสดงผลจบบท (+20 XP และ XP รวม)

**`draw_no_hearts()`** — หน้าหัวใจหมด มีปุ่มไป Practice Mode หรือกลับเมนู

### 14. Leaderboard

**`draw_leaderboard()`**
```python
ranking = sorted(self.data.items(),
                 key=lambda item: (-item[1]["xp"], -item[1]["streak"], item[1]["xp_time"]))
```
เรียงด้วย tuple 3 ค่า Python จะเทียบค่าแรกก่อน ถ้าเท่ากันค่อยดูค่าถัดไป:
1. `-xp` — ใส่ลบเพื่อให้ XP มากขึ้นก่อน (sorted เรียงจากน้อยไปมาก)
2. `-streak` — XP เท่ากัน streak มากกว่าขึ้นก่อน
3. `xp_time` — ยังเท่ากันอีก ใครถึง XP นั้นก่อน (เวลาน้อยกว่า) ขึ้นก่อน

แสดง 10 อันดับแรก แถวของผู้เล่นที่ล็อกอินอยู่ไฮไลต์สีเขียวอ่อน

### 15. หน้าเควสต์และ Achievement

**`draw_quests()`**
- **Daily Quests**: แต่ละเควสต์แสดง `(ทำได้/เป้าหมาย)` และแถบความคืบหน้าสีทอง (ใช้ `min(...)` ไม่ให้แถบยาวเกินเมื่อทำเกินเป้า)
- **Achievements**: จัดเป็น 2 คอลัมน์ (`i % 2` = คอลัมน์, `i // 2` = แถว) อันที่ได้แล้ววงกลมสีทอง ข้อความสีดำ ยังไม่ได้เป็นสีเทา

```
เปิดเกม
  └─> login ──(ล็อกอิน/สมัครสำเร็จ: refresh_day)──> menu
                                                    │
        ┌───────────────┬───────────────┬───────────┼──────────────┐
        ▼               ▼               ▼           ▼              ▼
   กดบทเรียน       Practice Mode    Quests &     Leaderboard     Log out
        │               │           Badges          │              │
  หัวใจ = 0 ?           │               │           Back           ▼
   ├─ ใช่ ─> no_hearts  │              Back          │           login
   └─ ไม่ ─> question <─┘               │            ▼
              │                         ▼          menu
        Check → feedback              menu
              │
        Continue (next_question)
         ├─ practice: ข้อสุ่มใหม่ (วนต่อ)
         ├─ หัวใจหมด: จำข้อที่ค้าง ─> no_hearts ─> Practice / Menu

         └─ ยังไม่ครบ: ข้อถัดไป
        ปุ่ม X: จำข้อที่ค้าง ─> menu
```

## วิธีเพิ่มบทเรียน / คำถามใหม่

แก้แค่ `questions.py` ไม่ต้องแตะ `main.py` เลย:

```python
LESSONS = [
    ...,
    {
        "name": "Colors",
        "questions": [
            {"type": "choice", "question": 'What does "rojo" mean?',
             "options": ["Red", "Blue", "Green", "Black"], "answer": "Red"},
            {"type": "order", "question": 'Translate: "The sky is blue"',
             "answer": ["El", "cielo", "es", "azul"], "extra": ["rojo"]},
        ],
    },
]
```

ข้อควรระวัง:
- `answer` ของข้อ `choice` ต้องสะกดตรงกับตัวเลือกตัวใดตัวหนึ่งใน `options` เป๊ะ ๆ
- ปุ่มบทเรียนในเมนูวางห่างกัน 80 px เริ่มที่ y = 160 หน้าจอสูง 600 จึงใส่ได้ประมาณ 5 บทก่อนปุ่มล้นจอ
- ข้อ `order` ที่มีคำเยอะ คำจะเรียงเป็นแถวเดียวจากซ้ายไปขวา ถ้ายาวเกินอาจล้นขอบจอ (กว้าง 800 px)
- ถ้าลบหรือย้ายลำดับคำถามเดิม รหัสข้อผิด (`wrong`) และ `progress` ในไฟล์เซฟเก่าอาจชี้ไปผิดข้อ หรือชี้ไปข้อที่ไม่มีแล้วจนเกมเกิด error ได้ ควรเพิ่มต่อท้ายแทนการแทรกกลาง
